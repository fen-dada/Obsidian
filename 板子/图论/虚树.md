# 虚树

## 核心思想

保留关键点和必要的 LCA，把中间没有分叉的长链压成一条边。k 个不同关键点建出的虚树最多有 2k-1 个点。

建树过程：按 DFS 序排序 → 加入相邻点的 LCA → 再排序去重 → 用栈连接父子。

栈维护当前祖先链，弹栈后栈顶就是当前点的虚树父亲。补入相邻点的 LCA 后，所需的分叉点均已保留。

预处理 O(n log n)，单次建树 O(k log k + k log n)，虚树上的一次遍历 O(k)。

## 板子

C++17，1 下标，全局数组，vector 邻接表。原树预处理一次，每次调用 build(a) 传入本次关键点。

```cpp
#include <bits/stdc++.h>
using namespace std;

using ll = long long;
const int N = 200005, LOG = 20;

vector<int> e[N];
vector<pair<int,int>> ve[N]; // 虚树：{儿子，原树路径长度}

int dep[N], fa[N][LOG];
int dfn[N], out[N], tim;
vector<int> ver; // 本次虚树的所有点，按 dfn 排序

void dfs(int u,int f){
    dep[u] = dep[f]+1;
    fa[u][0] = f;
    dfn[u] = ++tim;

    for(int i=1;i<LOG;++i){
        fa[u][i] = fa[fa[u][i-1]][i-1];
    }
    for(auto v:e[u]){
        if(v==f) continue;
        dfs(v,u);
    }
    out[u] = tim;
}

int lca(int u,int v){
    if(dep[u]<dep[v]) swap(u,v);
    for(int i=LOG-1;i>=0;--i){
        if(dep[fa[u][i]]>=dep[v]){
            u = fa[u][i];
        }
    }
    if(u==v) return u;
    for(int i=LOG-1;i>=0;--i){
        if(fa[u][i]!=fa[v][i]){
            u = fa[u][i];
            v = fa[v][i];
        }
    }
    return fa[u][0];
}

bool cmp(int u,int v){
    return dfn[u]<dfn[v];
}

bool anc(int u,int v){
    return dfn[u]<=dfn[v] && dfn[v]<=out[u];
}

// 返回虚树根；空集返回 0。
// ve 只存父亲到儿子的有向边。
int build(vector<int> a){
    // 只清理上一次用过的点，避免每次 O(n)。
    for(auto u:ver) ve[u].clear();
    ver.clear();
    if(a.empty()) return 0;

    sort(a.begin(),a.end(),cmp);
    a.erase(unique(a.begin(),a.end()),a.end());

    int k = a.size();
    for(int i=1;i<k;++i){
        a.push_back(lca(a[i-1],a[i]));
    }

    sort(a.begin(),a.end(),cmp);
    a.erase(unique(a.begin(),a.end()),a.end());
    ver = a;

    vector<int> st;
    st.push_back(a[0]);
    for(int i=1;i<(int)a.size();++i){
        int u = a[i];
        while(!anc(st.back(),u)){
            st.pop_back();
        }
        int f = st.back();
        ve[f].push_back({u,dep[u]-dep[f]});
        st.push_back(u);
    }
    return a[0];
}
```

### 调用方式

```cpp
dfs(1,0); // 原树建好后，只预处理一次

vector<int> a = {2,5,8}; // 本次关键点
int rt = build(a);

// 在 ve 上做树形 DP。
// ver 包含关键点，以及补进来的 LCA。
```

ver 按 dfn 排序，倒序遍历可以保证儿子先于父亲计算，适合自底向上的 DP。多次询问不需要重新预处理原树。

## 经典用法

### 1. 连接所有关键点的最小子树

所有虚树边的长度之和，就是原树上连接这些关键点的最小子树的边数。

```cpp
ll ans = 0;
for(auto u:ver){
    for(auto [v,w]:ve[u]){
        ans += w;
    }
}
```

适合“连接指定点至少需要多少条边”“求关键点的 Steiner 子树长度”。直接传入关键点，不要额外加入原树根，否则可能多算一段路径。

### 2. 所有关键点两两距离之和

设不同关键点总数为 K，虚树边 u → v 长度为 w，cnt[v] 是 v 子树中的关键点数。

这条边的贡献为：

$$
w\cdot cnt[v]\cdot(K-cnt[v])
$$

恰好有 cnt[v] × (K-cnt[v]) 对关键点分处这条边两侧。

```cpp
// 全局另开：bool key[N]; ll cnt[N];
// key[u] 只标记本次真正的关键点。
// 补进来的 LCA 不自动标记，K 为不同关键点数量。
ll ans = 0;
for(auto u:ver){
    cnt[u] = key[u];
}

for(int i=(int)ver.size()-1;i>=0;--i){
    int u = ver[i];
    for(auto [v,w]:ve[u]){
        ans += 1LL*w*cnt[v]*(K-cnt[v]);
        cnt[u] += cnt[v];
    }
}
```

这里统计无序点对，不用再除以 2。每次询问结束后，把本次关键点的 key 清掉。

### 3. 最小代价切断根与所有关键点的联系

原树边有非负删除代价，需要让根 1 无法到达任何关键点，且关键点不包含根。

预处理 mn[u]：原树根到 u 路径上的最小边权。令 mn[1] = INF，在带权原树 DFS 中计算 mn[v] = min(mn[u],边权)。INF 要大于可能的答案，并避免求和溢出。

本次建树额外加入根 1，但不要把它标成关键点：

```cpp
a.push_back(1);
int rt = build(a);
```

设 f[u] 为处理虚树中 u 子树的最小代价：

- u 是关键点：必须在根到 u 的路径上切断，f[u] = mn[u]。
- u 不是关键点：可以直接切断根到 u 的路径，也可以分别处理各个儿子，取两者较小值。

$$
f[u]=\min\left(mn[u],\sum_{v\text{ 是 }u\text{ 的儿子}}f[v]\right)
$$

```cpp
// 全局另开：ll mn[N], f[N]; bool key[N];
// mn 已在带权原树 DFS 中预处理；mn[1] = INF。
for(int i=(int)ver.size()-1;i>=0;--i){
    int u = ver[i];
    ll sum = 0;
    for(auto [v,w]:ve[u]){
        sum += f[v];
    }
    f[u] = key[u] ? mn[u] : min(mn[u],sum);
}
// 答案为 f[1]。
```

这个模型用的是 mn[u]，虚树边中的路径长度 w 不参与转移。原树的邻接表需要扩展为带权边，DFS 同时维护 mn；LCA 与建虚树逻辑不变。

## 易错点

- 虚树点不等于关键点，补进来的 LCA 要区分。
- 虚树边代表一整段原树路径，按题目保存路径长度、最小边权等信息。
- 原树带距离权重时，预处理根距离 dis[u]，将虚树边长换成 dis[u]-dis[f]，对应字段改为 ll。
- 每次只清理用过的点，不要在询问里清空整个长度为 n 的数组。build 只负责清理 ve，key 等辅助状态自行维护。
- N、LOG 按数据范围调整。递归预处理遇到很长的链时需注意栈空间。
- build 返回 0 表示关键点集合为空，不要再从 0 开始做普通树形遍历。
