给定序列 a[1..n]，笛卡尔树同时满足：

1. 中序遍历得到原序列下标 1..n；
2. 按 a[i] 建立小根堆，即父节点的 a 值不大于子节点。

下面代码使用单调栈 O(n) 建树。栈中保存当前树的右链，并且对应的 a 值单调不降。

处理 a[i] 时：

- 弹出所有 a 值大于 a[i] 的节点；
- 最后剩下的栈顶节点成为 i 的父亲，i 是它的右儿子；
- 最后弹出的节点成为 i 的左儿子。

```cpp
void build(int n){
    for(int i=1;i<=n;++i){
        int k = top;
        while(k && a[stk[k]]>a[i]) k--;
        if(k) rs[stk[k]] = i;
        if(k<top) ls[i] = stk[k+1];
        stk[++k] = i;
        top = k; 
    }
}
```
