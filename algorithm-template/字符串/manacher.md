```cpp
// abc -> #a#b#c#
void manacherss(const string& a) {
    n = a.length() * 2 + 1;
    for (int i = 0, j = 0; i < n; i++) {
        ss[i] = (i & 1) == 0 ? '#' : a[j++];
    }
}

int manacher(const string& str) {
    manacherss(str);
    int ans = 0;
    for (int i = 0, c = 0, r = 0, len; i < n; i++) {
        len = r > i ? min(p[2 * c - i], r - i) : 1;
        while (i + len < n && i - len >= 0 &&
               ss[i + len] == ss[i - len]) {
            len++;
        }
        if (i + len > r) {
            r = i + len;
            c = i;
        }
        ans = max(ans, len);
        p[i] = len;
    }
    return ans - 1;
}
```

## 变量含义

- `ss`：插入 `#` 后的字符串，长度 `n = 原串长度 * 2 + 1`。
- `p[i]`：`ss` 中以 `i` 为中心的最大回文半径，**包含中心**，最小为 `1`。
- `c`：当前右边界最远的回文中心；`r`：该回文右边界的下一个位置，**不包含 `r`**。
- `2*c-i`：`i` 关于 `c` 的镜像位置。借用其半径时，最多借到 `r`，之后继续扩展。

## 下标与长度换算

以下下标从 `0` 开始，`i` 是转换串中心，`p = p[i]`。

| 要求什么 | 公式 |
| --- | --- |
| 原串字符 `s[k]` 在转换串的位置 | `2*k+1` |
| 转换串回文长度 | `2*p-1` |
| 转换串回文左右端点（都包含） | `i-p+1`、`i+p-1` |
| **原串回文长度** | **`p-1`** |
| 原串起点 `L` | `(i-p+1)/2` |
| 原串右端点（不包含） | `(i+p-1)/2` |
| 取出原串回文 | `str.substr(L, p-1)` |

原串回文长度为 `L` 时，插入 `#` 后长度为 `2*L+1 = 2*p-1`，所以 **`L = p-1`**。

例如 `abba -> #a#b#b#a#`，中心 `i=4`，半径 `p[4]=5`：原串长度 `5-1=4`，起点 `(4-5+1)/2=0`，取出 `str.substr(0,4)` 即 `abba`。

- `i` 为奇数：中心是原字符 `s[i/2]`，对应奇数长度回文；原串包含中心的半径为 `p/2`。
- `i` 为偶数：中心是分隔符，在原串下标 `i/2` 的前面，对应偶数长度回文；原串每侧长度为 `(p-1)/2`。

时间复杂度 `O(N)`，空间复杂度 `O(N)`，`N` 为原串长度。
