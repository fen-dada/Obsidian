# PDF code font

These unmodified files match the local Sublime Text setting `font_face: FiraCode Nerd Font`:

- `FiraCodeNerdFont-Regular.ttf`
- `FiraCodeNerdFont-Bold.ttf`

Font metadata: Fira Code 6.002, Nerd Fonts 3.4.0.
Upstream: https://github.com/ryanoasis/nerd-fonts/tree/v3.4.0/patched-fonts/FiraCode

The fonts are bundled so CI needs no additional font download. See the accompanying Fira Code and Nerd Fonts license notices.
Chinese code comments continue to use Noto Sans Mono CJK SC through xeCJK.
